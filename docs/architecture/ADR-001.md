# ADR 001 FitFlow Technology Stack

## Status

Accepted

## Context

FitFlow requires Android, iOS and web support. The system must provide AI-powered workout recommendations, camera-based food recognition, progress tracking, private community groups, notifications and real-time updates.

The findings from Labs 1 and 2 showed four main problems:

- Personalization Gap
- Social Isolation
- Nutrition Tracking Friction
- Waning Motivation

Variant A, the AI-First Dashboard, was selected in Lab 3 with a score of 23 out of 25. The usability test in Lab 4 achieved a SUS score of 81.2, a task-completion rate of 85.7% and an average SEQ score of 5.74.

## Decision

The following technology stack was selected:

- React Native with Expo for the mobile application
- React Native Web for the web application
- Node.js with Express for the backend
- Firebase Firestore for the database
- Firebase Authentication for user login
- TensorFlow Lite and ML Kit for AI functions
- Socket.IO and Firebase for real-time features

## Reasons for the Decision

This stack matches the FitFlow case study and allows the development team to reuse code across different platforms. It supports rapid development, real-time updates, offline mobile access and camera integration. It is also suitable for a mid-sized development team.

## Positive Consequences

- Faster application development
- High level of code reusability
- Real-time community updates
- Offline mobile support
- Easy integration with AI and camera functions
- Lower initial development cost

## Negative Consequences

- Some platform-specific functions may require native code
- Firebase costs may increase when the number of users grows
- Firebase security rules must be configured carefully
- Complex reporting may require an additional database in the future

## Lab 4 Improvements

The implementation should include:

- A visible Change Exercise label
- A confirmation after accepting a workout plan
- A shorter onboarding process with a step indicator
- An easy manual correction option for food recognition
- A clear privacy label for private groups
- Larger text on progress charts
