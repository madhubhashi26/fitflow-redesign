# FitFlow Technology Stack

The following technologies were selected based on the FitFlow case study and the findings from Lab Exercises 1, 2, 3 and 4.

## Frontend

React Native with Expo was selected for the Android and iOS mobile applications. React Native Web can be used to provide a web version using shared components.

## Backend

Node.js with Express was selected for the main backend API. It can manage users, workout plans, nutrition records, progress, community groups and notifications.

## Database

Firebase Firestore was selected because it supports real-time data updates, offline mobile access and easy integration with React Native.

## Authentication

Firebase Authentication will be used for registration, login and identity management.

## AI and Machine Learning

TensorFlow Lite and ML Kit will support personalized workout recommendations and camera-based food recognition.

## Real-Time Features

Firebase real-time listeners and Socket.IO can support community feeds, private challenges and live updates.

## Final Selected Stack

- React Native with Expo
- React Native Web
- Node.js with Express
- Firebase Firestore
- Firebase Authentication
- TensorFlow Lite
- ML Kit
- Socket.IO
